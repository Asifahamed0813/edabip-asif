# EDABIP Settings Dashboard

A responsive settings dashboard built with **HTML, CSS, and vanilla JavaScript**. The project focuses on a clean settings experience with interactive controls, account/security options, role permissions, and accessibility.

## Features

- Responsive layout for desktop, tablet, and mobile
- Search and filter functionality
- Collapsible settings sections
- Notification and 2FA toggle controls
- Integration connect/disconnect demo
- Show/hide password functionality
- Roles Overview and Permission Matrix tabs
- Form validation with toast feedback
- Accessible labels and keyboard focus states
- Clean, modern settings dashboard UI

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- No external frameworks or UI libraries

   ```bash

   ```

2. Open the project folder.

3. Open `index.html` in a browser.

## Purpose

This project demonstrates how a settings dashboard can combine responsive design, interactive JavaScript behavior, form validation, security-related settings, role-based permissions, and accessibility in a single user interface.
