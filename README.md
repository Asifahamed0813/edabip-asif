# EDABIP Settings Dashboard

Responsive front-end recreation of the EDABIP Settings screen using **HTML, CSS and vanilla JavaScript only**.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Files
- `index.html` — semantic dashboard markup.
- `style.css` — CSS variables, layout and responsive design.
- `script.js` — sample data and interactions.

## Features
- Responsive desktop/tablet/mobile layout.
- Search/filter.
- Collapsible sections.
- Notification and 2FA toggles.
- Integration connect/disconnect demo.
- Show/hide password.
- Roles Overview / Permission Matrix tabs.
- Form validation and toast feedback.
- Accessible labels and keyboard focus.

## Note
This is a front-end-only assignment. There is no backend or database yet.

## Difficult part
The main challenge was matching the screenshot's dense three-column form, card spacing, sidebar proportions, tables and responsive behaviour using only CSS.
